How it works

A small neural network, trained on demonstrations, drives the arm. Every 80 ms it looks at the last eight frames from the wrist camera and at the joint angles, and plans the next arm and gripper targets.

For the last few centimetres a hand-written vision controller takes over. It finds the part and the box in the camera image and corrects the arm so the jaws close on the moving part. The gripper only opens once the part is held, lifted and lowered into the box.

Smoother arm motion

The network sends a new arm target every 40 ms. Originally each target was held fixed until the next one arrived, so the motors followed a staircase and the arm shook. The target now moves in a straight line from one value to the next within each step. The network itself is unchanged.

Results

Each condition was run 200 times with random seeds that were never used in training, and the network was not changed between runs. A run counts as placed when the part has been released, lies inside the box and has come to rest.

ConditionPickedPlaced
Default scene99.5 %99.0 %
Random lighting, part colour and camera mount99.0 %97.5 %
Box moved to positions not seen in training99.5 %99.5 %
Furnished hall, not seen in training100 %99.5 %

All numbers come from simulation with a single part type and conveyor layout. They were measured before the motion smoothing was added; the smoothing was checked separately on 44 runs, all of them placed.

Run it locally

Install the requirements, then start the server. It opens this page in your browser with the live simulation.

pip install -r requirements.txt
python web/server.py

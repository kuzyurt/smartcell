Not in this repository (and why)
================================

Files that were needed while the figures, media and smoothing experiments
were produced, but that a reader of the project does not need. They are
kept outside the repository. Their last version is in the git history
(commit "Redraw README figures ..." and earlier) if anyone wants it back.

Moved out of the repo
---------------------
tools/make_figures.py     Generated media/architecture.svg, pipeline.svg and
                          results.svg. The SVGs are the deliverable; the
                          generator is a one-off.
tools/render_media.py     Rendered media/hero.mp4, before.mp4, after.mp4 and
                          hero_poster.jpg from the Blender-dressed cell. The
                          videos are committed; the renderer is a one-off.

Working files that never entered the repo
-----------------------------------------
CPU-only wrapper that patched torch.load / "cuda:0" for the sandbox used
to measure the smoothing profiles (the web server has its own small shim).
Jerk analysis helper for evaluate.py traces and the raw per-run JSON/logs
of the first smoothing experiments. The per-episode results that back the
README numbers are kept in reports/smoothing_validation_20261123.json.
Screenshot and mock-page scripts used to check the figures and the site.
Local build output (dist/) and Python caches (__pycache__/).

Where the working files are now
-------------------------------
Session scratch area, outside the repository (not versioned). Anything
worth keeping should be copied from there before the session is cleaned up.

Kept in the repo on purpose
---------------------------
tools/measure_smoothing.py   Reproduces the smoothness numbers in the README.
tools/build_site.py          Builds the static site for Cloudflare Pages.
